# Typhoon CloudVault — Frequently Asked Questions

## What is Typhoon CloudVault?

Typhoon CloudVault is a secure cloud storage and backup service designed for small-to-medium businesses. It provides automatic file synchronization, end-to-end encryption, and team collaboration features. CloudVault integrates with popular productivity tools including Google Workspace, Microsoft 365, and Slack.

## What are the pricing tiers?

CloudVault offers three plans:

### Starter — $9/user/month
- 100 GB storage per user
- File sync across 3 devices
- 30-day version history
- Email support (business hours)

### Professional — $19/user/month
- 1 TB storage per user
- Unlimited device sync
- 1-year version history
- Priority email and chat support
- Team folders and shared workspaces
- Admin console with usage analytics

### Enterprise — $39/user/month
- Unlimited storage
- Unlimited device sync
- Unlimited version history
- 24/7 phone, email, and chat support
- Advanced admin controls and audit logs
- SSO integration (SAML 2.0, OIDC)
- Custom data residency options
- Dedicated account manager

All plans include a 14-day free trial with no credit card required.

## What file types does CloudVault support?

CloudVault supports all file types. There are no restrictions on file extensions or formats. Individual files can be up to 15 GB on the Starter plan, 50 GB on Professional, and 100 GB on Enterprise.

## Is there a desktop application?

Yes. CloudVault offers native desktop applications for Windows 10+, macOS 12+, and Ubuntu 22.04+. The desktop app creates a sync folder on your local machine and keeps files automatically synchronized. You can also access files through the web interface at app.typhooncloudvault.com.

## Is there a mobile app?

Yes. CloudVault has mobile apps for iOS 16+ and Android 13+. The mobile apps support automatic photo and video backup, offline file access, and document scanning with OCR.

## How does file sharing work?

You can share files and folders with anyone by generating a share link. Options include:

- **View only** — recipients can view and download but not edit
- **Edit access** — recipients can modify files directly
- **Password protected** — require a password to access the link
- **Expiring links** — links automatically deactivate after a set date
- **Internal only** — restrict sharing to members of your organization

Team folders on Professional and Enterprise plans allow entire groups to collaborate on shared file sets with granular permission controls.

## Does CloudVault support file versioning?

Yes. Every time a file is modified, CloudVault saves a new version. You can browse and restore any previous version within your plan's version history window (30 days for Starter, 1 year for Professional, unlimited for Enterprise). Versioning works for all file types.

## What regions are available for data storage?

CloudVault operates data centers in the following regions:

- United States (Virginia, Oregon)
- European Union (Frankfurt, Dublin)
- Asia Pacific (Tokyo, Sydney)
- Canada (Montreal)

Enterprise customers can request specific data residency configurations to meet regulatory requirements such as GDPR or SOC 2.

## Can I migrate from another cloud storage provider?

Yes. CloudVault includes a free migration tool that supports importing from Google Drive, Dropbox, OneDrive, and Box. The migration tool preserves folder structure, sharing permissions, and version history where supported. For large migrations (over 5 TB), our support team can assist with a managed migration at no additional cost.
